# IA con Google Gemini

- **Fecha:** 2026-05-23
- **Área:** ia
- **Estado:** activa
- **Autor/es:** Equipo IA / backend

## Contexto

DulIA debe analizar perfiles en español, sugerir rutas de carrera y cruzar con ofertas laborales. Se necesita un LLM accesible durante el hackathon.

## Decisión

Usar **Google Gemini API** como modelo principal. Prompts centralizados en [`../PROMPTS.md`](../PROMPTS.md).

## Por qué

- API disponible con tier gratuito para el evento.
- Buen rendimiento en español colombiano.
- SDK oficial integrable desde FastAPI.

## Alternativas descartadas

| Alternativa | Por qué no |
|-------------|------------|
| OpenAI GPT-4 | Costo / cuotas en hackathon |
| Claude | Menos alineado con disponibilidad del equipo en el momento |

## Consecuencias

- Backend orquesta llamadas; el frontend **nunca** llama a Gemini directo.
- Cambios de prompt = actualizar `PROMPTS.md` + versión en el log de prompts.
- Latencia de API: frontend muestra loading mientras el backend procesa.
